IMPORTANT NOTES

1. Create users first before testing tables that use UserID.

2. Create store items first before testing Inventory.

3. Create achievements first before testing UserAchievements.

4. Create tasks first before testing TaskSchedules and TaskProgress.

5. Make sure NotificationType has data before testing Notification.

6. Make sure DayOfWeek has data before testing TaskSchedules.

7. If a JSON test uses UserID, TaskID, ItemID, AchievementID, NotificationTypeID, or DayofWeekID, adjust the number to match existing IDs in your own database.

8. PasswordHash should not be sent from the frontend. Send Password instead. The backend hashes it before saving it.
